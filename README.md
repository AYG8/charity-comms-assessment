# مؤشر جاهزية العلاقات العامة والإعلام والاتصال المؤسسي

استطلاع عربي باتجاه RTL، مستند إلى خطة تحسين العمل الإعلامي للجمعيات الخيرية بمنطقة عسير. يتضمن واجهة الاستطلاع، تحليلاً إجمالياً، تقريراً فردياً، وطريقة تصدير واستيراد النتائج.

## تشغيل محلي

افتح `index.html` في متصفح حديث للتحليل، أو `survey.html` لصفحة الاستطلاع المستقلة. رابط صفحة الاستطلاع المنشور: `https://ayg8.github.io/charity-comms-assessment/survey.html?v=20261011-5`. يمكن تشغيله بخادم ملفات محلي عند الحاجة. لا يحتاج إلى بناء أو مكتبات JavaScript.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديداً، وارفع محتويات هذا المجلد إلى الفرع `main` (يجب أن يكون `index.html` في جذر المستودع).
2. من إعدادات المستودع افتح **Pages**، واختر **GitHub Actions** كمصدر النشر.
3. شغّل سير العمل `Deploy static assessment to GitHub Pages` من تبويب **Actions** أو ادفع تغييراً إلى `main`.
4. سيعرض GitHub رابط Pages بعد نجاح سير العمل.

سير العمل الموجود في `.github/workflows/pages.yml` ينشر الموقع من جذر المستودع.

## الربط المركزي للإجابات

GitHub Pages لا يستقبل البيانات بذاته. يتضمن المشروع الآن واجهة مزامنة ومخزن Google Apps Script/Sheets (`Code.gs`). بعد نشر السكربت كـ Web App، ينشئ السكربت جدول الاستجابات في حساب الناشر؛ يرسل نموذج الجمعية الإجابة إليه، وتقرأ لوحة التحليل القائمة عند فتحها أو عند الضغط على «تحديث النتائج». لكل جمعية سجل واحد قابل للتحديث بحسب اسمها.

### تفعيل الربط

1. افتح [script.google.com](https://script.google.com) بحساب الجهة المالكة للبيانات، وأنشئ مشروعًا جديدًا.
2. استبدل محتوى `Code.gs` في المشروع بالكود الموجود في هذا المستودع، ثم احفظه.
3. من **Project Settings → Script Properties** أضف الخاصية `DASHBOARD_READ_KEY` وضع لها رمزًا قويًا من اختيارك. احتفظ به؛ ستدخله في لوحة التحليل.
4. اختر **Deploy → New deployment → Web app**، واجعل التنفيذ بحسابك، والوصول **Anyone**، ثم وافق على الصلاحيات وانسخ رابط `/exec`.

عند تحديث `Code.gs` لاحقًا، افتح **Deploy → Manage deployments → Edit**، واختر **New version** ثم **Deploy**. يبقى رابط `/exec` نفسه.
5. أرسل رابط `/exec` لي؛ أضعه في `backend-config.js` وأنشر تحديث الموقع. لا يعتبر الربط مفعّلًا قبل هذه الخطوة والتحقق من أول إجابة.

تُنشأ ورقة Google الخاصة بالاستجابات في حساب الناشر. إرسال الإجابات متاح لحاملي رابط الاستطلاع؛ أما قراءة النتائج فتتطلب رمز لوحة التحليل. لا تُدخل بيانات أفراد أو مستفيدين أو معلومات حساسة. تأكد من أن هذا الاستخدام مناسب لسياسة جمعيتك قبل نشر رابط الاستطلاع.

الإجابات التي أُرسلت قبل تفعيل الربط ما زالت محفوظة في متصفح المجيب فقط؛ صدّرها من ذلك المتصفح واستورد JSON في لوحة التحليل بعد تفعيل الخدمة. لا يمكن للموقع استرجاع ردود جهاز آخر من دون ملف التصدير.

حتى وضع رابط الخدمة في `backend-config.js`، يستمر النموذج في الحفظ المحلي ويعلن بوضوح أن الربط المركزي غير مفعّل. لا تضع كلمات مرور أو مفاتيح سرية في ملفات الواجهة أو المستودع العام.

## بنية القياس

المحاور الموزونة (مجموعها 100%):

| المحور | الوزن | ما يغطيه من الخطة |
|---|---:|---|
| السياسات والامتثال والخصوصية | 20% | بناء السياسة، الضوابط الرسمية، الأمن السيبراني، حماية الخصوصية، اعتماد المجلس، التعميم والتطبيق |
| الخطة الإعلامية والتكامل الداخلي | 20% | بناء الخطة بالتعاون مع الإدارات، تحسين الصورة/توظيف المعلومة، إجراءات التنفيذ والمؤشرات |
| حوكمة الإعلان والنشر | 15% | مسؤول المحتوى، المراجعة اللغوية، إقرار المدير التنفيذي، تطبيق مسار النشر |
| الهوية البصرية الإعلامية | 10% | وجود الهوية والقوالب وتطبيقها على مخرجات النشر |
| التقييم وقياس التنفيذ والأثر | 15% | تقييم الأعمال، التغذية الراجعة، قياس الأثر والمتابعة نصف السنوية |
| العلاقات العامة والاتصال المؤسسي | 15% | الانتقال إلى اتصال مؤسسي، التنسيق الداخلي، الاتصال مع أصحاب المصلحة |
| القدرات والتمكين التشغيلي | 5% | وضوح التكليفات والموارد والتدريب اللازم للتنفيذ |

الوزن والعتبات اجتهاد تصميمي معلن في الأداة لتكوين مقياس تشخيصي؛ لم تنص الخطة على أوزان رقمية أو عتبات جاهزية. خيارات الإجابة ثلاثة فقط: «متحقق» = 100، «جزئي» = 50، «غير متحقق» = 0. جميع البنود مطلوبة، وتحسب الدرجة بعد اكتمالها باستخدام أوزان المحاور الثابتة (مجموعها 100%) من دون استبعاد بند أو إعادة توزيع وزن. الاستجابات القديمة أو المستوردة غير المكتملة لا تحصل على درجة كلية حتى تستكمل. حدود التصنيف المقترحة: 80 فأكثر متمكن؛ 60 إلى أقل من 80 مطبق جزئياً؛ 40 إلى أقل من 60 قيد التطوير؛ أقل من 40 أولوية تأسيس.

النتيجة أداة فرز وتطوير ذاتي وليست اعتماداً أو تحققاً ميدانياً. استوثق من الوثائق والعينات والممارسة قبل اعتماد القرار.
